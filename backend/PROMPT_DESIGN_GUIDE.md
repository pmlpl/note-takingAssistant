## 🎯 Prompt 设计原则

### 1. 角色定义清晰
让 AI 明确自己的身份和职责：
```
你是一位专业的学习笔记助手，专门为大学生和自学者创建高质量的学习笔记。
```

### 2. 输出格式规范
明确指定输出格式和要求：
```
- 使用 Markdown 格式
- 包含清晰的标题层级（# ## ###）
- 重要概念使用 **加粗** 标注
```

### 3. 结构化要求
给出具体的内容结构：
```
请按照以下结构生成笔记：
1. 核心概念介绍
2. 关键知识点详解（分点阐述）
3. 实际应用或示例
4. 总结与复习要点
```

### 4. 质量约束
设置质量和长度限制：
```
- 字数控制在 500-800 字
- 语言简洁明了，适合学习复习
```

## 🔨 用户提示词构建

### 1. 基础生成提示词

```python
user_prompt = f"请为主题「{topic}」生成一篇学习笔记。"

if keyword:
    user_prompt += f"\n\n重点关注的关键词：{keyword}"
```

### 2. 带参考材料的提示词

```python
if reference_notes and len(reference_notes) > 0:
    user_prompt += "\n\n以下是参考材料，请结合这些内容生成笔记：\n"
    for i, note in enumerate(reference_notes, 1):
        user_prompt += f"\n【参考资料{i} - {note.get('filename', '未知文件')}】\n"
        content = note.get("content", "")
        if len(content) > 2000:
            content = content[:2000] + "...（内容过长，已截断）"
        user_prompt += content
```

### 3. 结构化要求

```python
user_prompt += "\n\n请按照以下结构生成笔记：\n"
user_prompt += "1. 核心概念介绍\n"
user_prompt += "2. 关键知识点详解（分点阐述）\n"
user_prompt += "3. 实际应用或示例\n"
user_prompt += "4. 总结与复习要点\n"
```

### 4. 分析任务提示词

```python
user_prompt = f"""请对以下学习笔记进行专业分析和评估：

【笔记内容】
{content}

请从以下几个维度进行分析：
1. 内容完整性：是否覆盖了主题的核心知识点
2. 结构清晰度：逻辑是否清晰，层次是否分明
3. 表达准确性：概念解释是否准确，语言是否通顺
4. 实用性：是否便于复习和理解

请以严格的 JSON 格式返回分析结果，不要包含其他文字或 Markdown 标记。"""
```

## ⚙️ 参数调优建议

### Temperature（创造性控制）

| 值范围 | 效果 | 适用场景 |
|--------|------|----------|
| 0.1-0.3 | 非常保守，重复性高 | 笔记分析、事实性问题 |
| 0.4-0.6 | 平衡创造性和准确性 | 一般性内容生成 |
| 0.7-0.9 | 更具创造性，更多样化 | 创意写作、头脑风暴 |

**我们的配置：**
- 笔记生成：`temperature=0.7`（需要一定的创造性）
- 笔记分析：`temperature=0.3`（需要稳定性和一致性）

### num_predict（最大生成长度）

| 值 | 说明 |
|----|------|
| 500-1000 | 短文本，快速响应 |
| 1000-2000 | 中等长度，适合笔记生成 |
| 2000+ | 长文本，详细内容 |

**我们的配置：**
- 笔记生成：`num_predict=2000`
- 笔记分析：`num_predict=1000`

## ❓ 常见问题与优化

### 问题 1：AI 返回格式不符合预期

**现象：** 要求 JSON 格式，但 AI 返回了 Markdown 或其他格式

**解决方案：**
1. 在系统提示词中强调"必须返回严格的 JSON 格式"
2. 在用户提示词中再次提醒"不要包含其他文字或 Markdown 标记"
3. 添加后处理逻辑，提取 JSON 部分

```python
# 提取 JSON 部分
if "```json" in result_text:
    result_text = result_text.split("```json")[1].split("```")[0].strip()
elif "```" in result_text:
    result_text = result_text.split("```")[1].split("```")[0].strip()
```

### 问题 2：内容过长或过短

**现象：** 生成的笔记超出预期长度

**解决方案：**
1. 在提示词中明确字数要求
2. 使用 `num_predict` 参数限制最大长度
3. 对输入内容进行截断处理

```python
# 限制参考内容长度
if len(content) > 2000:
    content = content[:2000] + "...（内容过长，已截断）"
```

### 问题 3：AI 忽略参考材料

**现象：** 上传了参考笔记，但 AI 没有充分利用

**解决方案：**
1. 在提示词中明确说明"请结合这些内容生成笔记"
2. 将参考材料放在显眼位置，使用特殊标记
3. 在系统提示词中强调"参考材料的重要性"

```python
user_prompt += "\n\n以下是参考材料，请结合这些内容生成笔记：\n"
for i, note in enumerate(reference_notes, 1):
    user_prompt += f"\n【参考资料{i} - {note.get('filename', '未知文件')}】\n"
```

### 问题 4：JSON 解析失败

**现象：** AI 返回的内容无法解析为 JSON

**解决方案：**
1. 添加异常处理，捕获 `json.JSONDecodeError`
2. 提供友好的错误提示
3. 记录原始返回内容，便于调试

```python
except json.JSONDecodeError as e:
    raise Exception(f"AI 返回格式错误，请重试。错误信息：{str(e)}")
```

## 🎓 最佳实践总结

### ✅ 应该做的

1. **明确角色定位**：让 AI 知道自己是"学习笔记助手"
2. **详细输出要求**：指定格式、结构、长度等
3. **提供参考材料**：让 AI 有更多上下文信息
4. **设置合理参数**：根据任务类型调整 temperature
5. **添加错误处理**：优雅地处理异常情况

### ❌ 不应该做的

1. **模糊的指令**：避免"写得好一点"这种模糊要求
2. **过长的输入**：注意 token 限制，适当截断
3. **忽略格式验证**：始终验证 AI 返回的数据格式
4. **单一尝试**：如果结果不理想，可以重新生成
5. **硬编码提示词**：使用模板和变量，便于维护
