# 桌面端 UI 重设计方案

> 版本：v1.0
> 日期：2026-07-01
> 状态：待评审

## 1. 概述

将桌面端从 "Web 套壳" 模式改造为真正的桌面应用体验，包括自定义标题栏、常驻侧边栏、三栏布局、全局快捷键、拖拽导入、系统通知等桌面端专属功能。

## 2. 设计目标

- **视觉差异化**：桌面端有自己的视觉语言，与 Web 端明显区分
- **原生体验**：自定义标题栏、全局快捷键、系统通知等桌面原生能力
- **高效布局**：三栏布局提升信息密度和操作效率
- **代码独立**：桌面端代码完全独立，与 Web 端无耦合

## 4. 详细设计

### 4.1 P0：UI 桌面化

#### 4.1.1 自定义标题栏（TitleBar）

**文件**：`components/desktop/TitleBar.vue`

**功能**：
- 左侧：应用图标 + 应用名称 "NoteMind"
- 中间：可拖拽区域
- 右侧：最小化、最大化/还原、关闭按钮
- 鼠标悬停效果、按钮按下效果

**主进程修改**：
- `main.js` 中创建窗口时设置 `frame: false`
- 注册窗口控制 IPC（minimize/maximize/close）

**样式**：
- 高度：36px
- 背景：深色/浅色（跟随系统主题）
- 与内容区有明确分界（底部细线分隔）

#### 4.1.2 常驻侧边栏（DesktopSidebar）

**文件**：`components/desktop/DesktopSidebar.vue`

**功能**：
- 常驻左侧，宽度 64px（图标模式）
- 鼠标悬停展开到 200px（图标+文字）
- 导航项：首页、笔记、AI 生成、AI 摘要、翻译、思维导图、知识图谱、用户中心
- 底部：设置、退出登录

**样式**：
- 背景：深色/浅色（与标题栏统一）
- 选中项高亮
- 展开动画

#### 4.1.3 桌面端路由调整

**文件**：`router/index.js`

- 根路径 `/` → 未登录跳 `/login`，已登录跳 `/home`
- 移除欢迎页 Welcome 路由（桌面端不需要）
- 登录/注册页使用独立布局（无边栏、有标题栏）

### 4.2 P1：原生能力

#### 4.2.1 全局快捷键

**主进程修改**：
- 使用 `globalShortcut` 注册快捷键
- 通过 IPC 通知渲染进程

**快捷键列表**：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+N` | 新建笔记 |
| `Ctrl+Shift+F` | 打开搜索 |
| `Ctrl+1` ~ `Ctrl+4` | 切换前 4 个导航项 |

**渲染进程**：
- `composables/useGlobalShortcut.js` 封装快捷键事件监听

#### 4.2.2 拖拽导入

**功能**：
- 拖拽文件到窗口时显示半透明遮罩
- 支持格式：.txt、.md、.docx、.pdf、.jpg、.png
- 释放后解析文件并创建新笔记
- 图片文件直接插入到当前笔记（如果在编辑页）

**实现**：
- `components/desktop/DragDropOverlay.vue` 遮罩组件
- `composables/useDragDrop.js` 拖拽逻辑封装
- 主进程 IPC 处理文件读取（支持大文件）

#### 4.2.3 系统通知

**功能**：
- AI 生成完成时发送系统通知
- 点击通知激活窗口并跳转到对应页面

**实现**：
- 主进程使用 `Notification` API
- 渲染进程通过 IPC 请求发送通知
- `composables/useNotification.js` 封装

### 4.3 P2：三栏布局

#### 4.3.1 笔记编辑三栏布局

**文件**：`views/desktop/NoteEditDesktop.vue`

**布局**：
- 左栏：笔记列表（可折叠，宽度 280px）
- 中栏：笔记编辑器（弹性宽度）
- 右栏：AI 助手面板（可关闭，默认关闭，宽度 360px）

**AI 助手面板**：
- 默认隐藏，点击右上角按钮打开
- 内容：AI 对话、摘要、翻译等快捷操作
- 可以关闭，关闭后中栏自动扩展

#### 4.3.2 首页三栏布局

**文件**：`views/desktop/HomeDesktop.vue`

**布局**：
- 左栏：导航（DesktopSidebar，已在布局层）
- 中栏：最近笔记 + 快捷操作
- 右栏：统计信息（笔记数量、AI 使用量、最近活动图表）

**统计面板内容**：
- 笔记总数
- 本周新增
- AI 调用次数
- 最近 7 天活动趋势图（ECharts）

## 5. 技术实现要点

### 5.1 主题适配
- 标题栏和侧边栏支持深色/浅色模式
- 跟随系统主题自动切换

### 5.2 性能优化
- 侧边栏展开/折叠使用 CSS transform 动画
- AI 面板使用 `<KeepAlive>` 缓存状态
- 大文件拖拽导入使用流式读取

### 5.3 错误处理
- 拖拽导入失败时提示用户
- 全局快捷键注册失败时降级（不影响主功能）
- 通知权限被拒绝时静默降级

## 6. 实施顺序

1. **Phase 1**：自定义标题栏 + 桌面端布局壳
2. **Phase 2**：常驻侧边栏 + 路由调整
3. **Phase 3**：全局快捷键 + 系统通知
4. **Phase 4**：拖拽导入
5. **Phase 5**：笔记三栏布局 + AI 面板
6. **Phase 6**：首页三栏布局 + 统计面板

## 7. 验收标准

- [ ] 窗口无系统原生标题栏，自定义标题栏功能正常（最小化/最大化/关闭/拖拽）
- [ ] 左侧常驻侧边栏，悬停展开，点击导航正常跳转
- [ ] 全局快捷键可用（新建笔记、搜索、切换页面）
- [ ] 拖拽文件进窗口显示遮罩，释放后正确导入
- [ ] AI 生成完成发送系统通知
- [ ] 笔记编辑页三栏布局正常，AI 面板可开关
- [ ] 首页三栏布局正常，统计数据正确展示
- [ ] 构建无错误，Electron 启动正常
